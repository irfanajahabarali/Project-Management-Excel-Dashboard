# Project Management Excel Dashboard

## Overview

This is an Excel-based Project Management Tracker and Dashboard created as a learning project to practice data analysis and visualization using Microsoft Excel.

## Key KPIs

* Total Projects
* Total Actual Cost
* Active Projects
* On Hold / Delayed Projects
* Average Project Age
* Budget Utilization

## Dashboard Analysis

* Monthly Actual Cost
* Projects by Location
* Projects by Status
* Projects by Category
* Projects by Department
* Projects by Priority

## Key Insights

* 75 projects are being tracked, with 37 currently active.
* 15 projects are delayed and 6 are on hold.
* 37 projects are marked as high priority.
* Budget utilization is 102.1%, indicating that actual costs have exceeded the overall budget.
* February recorded the highest monthly actual cost at ₹545K.
* Mumbai has the highest number of projects, with 18 projects.
* The dashboard provides a comparison of projects across status, category, department, location, and priority.

## Tools & Techniques

* Microsoft Excel
* PivotTables
* Excel Formulas
* Data Analysis
* Data Visualization
* Dashboard Development

## Purpose

The purpose of this project is to practice preparing project data, creating KPIs, analyzing data using PivotTables and presenting insights through an interactive Excel dashboard.
