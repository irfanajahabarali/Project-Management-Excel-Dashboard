# Project Management Excel Dashboard

## Overview

This is an Excel-based Project Management Tracker and Dashboard created as a learning project to practice data analysis and visualization using Microsoft Excel.

## Key KPIs

* Total Projects
* Total Actual Cost
* Active Projects
* On Hold / Delayed Projects
* Average Project Age
* Budget Utilization

## Dashboard Analysis

* Monthly Actual Cost
* Projects by Location
* Projects by Status
* Projects by Category
* Projects by Department
* Projects by Priority

## Tools & Techniques

* Microsoft Excel
* PivotTables
* Excel Formulas
* Data Analysis
* Data Visualization
* Dashboard Development

## Purpose

The purpose of this project is to practice preparing project data, creating KPIs, analyzing data using PivotTables and presenting insights through an interactive Excel dashboard.
